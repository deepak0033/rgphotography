How live publishing works

This admin portal controls the media structure of RG Photography. The website uses fixed filenames so replacing an image does not require changing the HTML.

Fixed filename rule: If the website currently uses:

assets/weddings/01.jpg

the replacement image must also be named: 01.jpg The future GitHub integration will replace the existing file and Vercel can deploy the updated website automatically.
